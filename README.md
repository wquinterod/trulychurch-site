# Truly Church (sitio de demostración)

Iglesia **ficticia** para mostrar a los pastores cómo Truly se incrusta en la página web de su iglesia: chat con Sofía, petición de oración y "Encuentra tu grupo", conectados a la Iglesia Demo de Truly.

- Generar: `node build.mjs` (escribe en `site/`).
- Publicado como sitio estático de Render (carpeta `site/`), dominio trulychurch.com.
- Separado a propósito del repositorio de Truly: nada de aquí afecta la app.
